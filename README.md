Full Stack Blogging Platform

Designed and developed a full-stack blogging platform focused on scalability, authentication, and content management. Built secure user workflows, optimized server-side rendering, and integrated third-party services to deliver a production-ready application with strong performance, SEO, and user experience.

Tech Stack: Next.js, MongoDB, NextAuth, Cloudinary, Tailwind CSS

To run this project:
  1. Open the root folder in terminal and run npm i.
  2. Run npm run dev.
  3. Open http://localhost:3000/ and explore my website.
